# CBHI Performance Monitoring Dashboard

## 1. Project Overview

This project demonstrates how public health monitoring and evaluation methods can be used to track Community-Based Health Insurance (CBHI) enrollment performance.

The project uses **synthetic data** to demonstrate how to compare enrollment targets with actual results, identify performance gaps, and communicate findings to decision-makers.

## 2. Project Objectives

- Monitor CBHI enrollment against established targets.
- Calculate target achievement and enrollment gaps.
- Compare performance across administrative areas and reporting periods.
- Identify areas requiring additional community mobilization.
- Develop evidence-based recommendations for improving enrollment performance.

## 3. Key Performance Indicators

- Enrollment target
- Actual enrollment
- Target achievement percentage
- Enrollment gap
- Change in enrollment over time
- Performance by administrative area

## 4. Tools

- Microsoft Excel — data preparation and analysis
- Microsoft Power BI — dashboard development and visualization
- GitHub — project documentation and version control

## 5. Data and Privacy

All data used in this demonstration will be synthetic and created for learning purposes. No identifiable personal information or confidential government records will be included.

## 6. Planned Deliverables

- Synthetic CBHI monitoring dataset
- Data cleaning and analysis
- Interactive performance dashboard
- Key findings and recommendations
- Project documentation
